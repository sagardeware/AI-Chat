✅ How to Verify Context is Working

  1. Open the chatbot widget (bottom-right corner)
  2. Send your first message
  3. Open browser DevTools → Network tab
  4. Look for the /api/chat/message request
  5. Check the request payload - it should include a context object with the values above
  6. In the backend database, the conversation's metadata field should contain this context

🔍 Expected Behavior

  • ✅ Context is sent ONLY on the first message (new conversation)
  • ✅ Context is stored in the database under conversation.metadata
  • ✅ Subsequent messages do NOT send context (only sessionId)
  • ✅ SDK works perfectly even without VetChatbotConfig
